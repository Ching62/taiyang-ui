# 太陽電玩組件庫

太陽電玩所有網頁共用的設計組件。風格是專業、高級、不花俏：石墨灰底、細線分隔，只用一道晨曦金當重點色。

## 怎麼看
打開 `index.html` 就是預覽目錄，每個組件都可以：
- 切換手機／桌機寬度預覽
- 開新分頁完整試玩
- 一鍵複製整份程式碼

整頁組合範例在 `templates/landing.html`。

## 怎麼請 Claude 使用
直接說「用組件庫的〇〇做一個△△頁面」，或「照首頁範本幫我改教學總網站」。Claude 會先讀這個儲存庫再動手。

## 目前收錄（32 個）
- 導覽：捲動變玻璃導覽列、後台側邊欄
- 主視覺：左右分欄主視覺、大字宣言主視覺
- 內容區塊：特色條列、不規則便當格、跑馬燈、數字跳動統計、步驟時間軸、常見問題、價格表、買家評價牆、行動呼籲橫幅、頁尾
- 卡片：聚光燈遊戲卡片、教學清單列
- 表單：密碼序號解鎖畫面、表單元件組、快速搜尋面板
- 回饋提示：通知訊息、對話框與側拉面板、載入中／空資料／錯誤狀態
- 資料呈現：可排序篩選資料表、關鍵數字＋迷你走勢、機器人狀態面板、即時動態清單
- 文字與背景：文字動態效果組、低調背景紋理組
- 小工具：滑動指示頁籤、一鍵複製區塊、閱讀進度＋回到頂端、深淺色切換
